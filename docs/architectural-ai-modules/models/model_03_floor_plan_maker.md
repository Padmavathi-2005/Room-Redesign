# Model 03: Floor Plan Maker (`floor-plan-maker`)

## 1. Overview
Interactive canvas sketcher and automated room partition divider engine.

---

## 2. Technical Neural Architecture
* **Core Model**: `HTML5 Canvas Vector Engine` + `CAD Lineart Vector Parser`.
* **Processing**: Converts user vector wall nodes into clean CAD JSON specs and line drawings.

---

## 3. Required User Inputs
* Interactive Wall Drawing Canvas (Nodes, Walls, Doors, Windows).
* Room Labels & Dimensions.

---
